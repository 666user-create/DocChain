# DocChain — 本地静默文档版本管理器

为文档工作者打造的零感知版本控制工具。在你专心写文档的同时，DocChain 静默守护每一次保存，让你随时回到任何一个历史版本。

## 为什么需要 DocChain？

办公室工作者日常面对大量 Word/Excel/PPT 文档，反复修改是常态。当你删掉一段文字、改了一个数据，几小时后才后悔——你需要的不是"撤销"，而是"回到那个版本"。Git 是为代码设计的，对办公用户并不友好。DocChain 填补了这个空白：

- **零感知自动存档** — 保存即提交，无需手动操作
- **原位追踪** — 文档留在原来的文件夹里，不需要复制搬家
- **无侵入** — 静默运行在系统托盘，不弹窗、不打扰

## 能做什么

### 多目录原位追踪
把任意多个文件夹加入监听列表（主面板左侧「+ 添加目录」），文档留在原地（`D:\文档\2025年\...`），DocChain 在后台追踪所有变更。每个监听目录下自动创建 `.docchain-git` 隐藏版本库，与你已有的 `.git` 互不干扰。

- **初始存档**：添加文件夹时，目录内已有文件自动建立基线版本——从加入那一刻起就可回滚
- **可随时移除**：停止监听不会删除任何东西，版本历史保留在原目录中，重新添加即恢复

### 智能文件监听
- 基于操作系统文件事件，不轮询磁盘，占用资源极低
- **2 秒防抖**：模拟 Office 保存行为，同一文件频繁写入只存档一次
- **智能过滤**：自动忽略 `~$` 锁定文件、`.tmp`/`.swp` 临时文件、系统元数据文件
- **无变更不提交**：逐字节比对内容，内容没变不产生空版本

### 版本时间线
- 左侧选目录、点文件，右侧立刻显示完整版本历史（最新在前）
- 每个版本卡片展示：时间戳、commit hash、变更摘要，蓝点自动存档、绿点手动操作
- **一键恢复**：任意版本一键回滚，文件立即还原，并留下一条回滚记录，历史不丢

### 系统托盘驻留
- 双击托盘图标（蓝底 D）打开主面板，右键 `Open Panel` / `Exit`
- 关闭主面板后继续静默驻留，开机常驻不打扰

## 快速开始

### 直接运行（绿色版，自带 JRE）

```bash
# 打包
./gradlew jpackage
# 输出: build/dist/DocChain/  →  双击其中的 DocChain.exe，托盘出现蓝底 D 图标
```

拷贝整个 `build/dist/DocChain/` 文件夹到任何机器都能运行，无需安装 Java。

### 从源码构建

```bash
./gradlew build     # 编译 + 运行全部测试
./gradlew run       # 直接运行
```

### 日常使用

1. 打开主面板 → 点「+ 添加目录」选择要追踪的文件夹
2. 正常编辑、保存你的文档——什么都不用管
3. 随时打开面板，点击文件查看它的完整版本历史
4. 想回到某个版本 → 点该版本卡片上的「恢复」

## 工作原理

```
文件保存 → 系统文件事件 → 2秒防抖聚合 → 逐字节比对
                                            ↓ 有变更
                              JGit 增量提交到该目录的 .docchain-git
                                            ↓
                                    面板时间线实时展示
```

每个监听目录一个独立版本库，互不影响；提交由内容比对驱动，绝不产生空版本。

## 数据存储

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| 版本历史 | `<监听目录>/.docchain-git/` | 每个目录独立的隐藏版本库 |
| 监听目录列表 | `%APPDATA%/DocChain/watched-directories.txt` | 一行一个路径的纯文本 |
| 应用日志 | `~/.docchain/logs/docchain.log` | 滚动日志，30 天保留 |

**完全本地**：所有数据只存放在你自己的电脑上，无网络通信、无遥测、无账号。
**不碰原文档**：DocChain 只读取文件内容做存档，从不修改或删除你的原始文件。

## 常见问题

**Q: DocChain 会影响电脑性能吗？**
A: 监听基于操作系统文件事件通知，不轮询磁盘。内存占用约 80-120MB（含 JVM）。

**Q: 每个目录下都有 `.docchain-git`，会不会很大？**
A: Git 只存储文件差异（delta），Office 文档本质是 ZIP 包，增量效率很高。一个包含 100 个版本的 `.docx`，仓库大小通常在原文件的 2-5 倍。

**Q: 能卸载吗？会删除我的原始文件吗？**
A: 随时可卸载，DocChain 永远不会删除你的原始文件。卸载只需删除程序目录；各监听目录下的 `.docchain-git/` 可保留（重装后重新添加目录即恢复历史）或手动删除。

**Q: 支持 macOS / Linux 吗？**
A: 支持。核心功能（监听、存档、时间线、恢复、托盘）全平台可用，差异仅在系统托盘的实现细节上。

**Q: 能追踪代码项目吗？**
A: 可以，但不推荐——对代码来说，专业 Git 客户端是更好的选择。DocChain 专为**非技术用户的文档版本管理**设计。
